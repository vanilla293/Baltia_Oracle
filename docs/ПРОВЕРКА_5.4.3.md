# Проверка 5.4.3 «решительный пилот» на стенде промптов (30.09.2026)

Стенд — `backend/prompt_bench.py`. В нём 14 выдуманных, но согласованных по числам биржевых ситуаций по SBER около
300 ₽ в режиме игры `auto`. Каждая ситуация — сцена на настоящих `Mission`/`MissionPilot`: 13 промптов из 14 совпадают
с боевыми байт в байт, вердикт собран теми же функциями. Промпты 5.4.2 («до») сняты стендом на коде 5.4.2. Промпты
5.4.3 («после») сняты на итоговом коде.

**Кто отвечал.** Ключа DeepSeek в среде разработки нет, поэтому за модель отвечали независимые агенты Claude
вслепую: каждый видел только system и user одного промпта, не знал версию и не видел проект. Каждая версия получила
по два ответа на ситуацию, всего 56 ответов. Ответы разобраны той же функцией, что у стенда
(`prompt_bench.parse` → `ai_v5.decision_of`).

**Главная оговорка.** Это не DeepSeek. На старых промптах агент Claude тоже почти всегда действовал, поэтому жалобу
«ждём, ждём» он не воспроизводит. Настоящий итог для отчёта о DeepSeek даёт только прогон с ключом:

```
python3 -m backend.prompt_bench --run --runs 3 --out отчёт.md --json отчёт.json
```

Это 14 ситуаций × 3 прогона ≈ 42 вызова PRO. Чтобы сравнить с 5.4.2, тот же стенд нужно запустить на коде 5.4.2.

## Итог прокси-прогона

| | до (5.4.2) | после (5.4.3) |
|---|---|---|
| действие или выход | 23 из 28 (82 %) | 24 из 28 (86 %) |
| ожидание вне рынка | 1 | 0 |
| удержание позиции | 4 | 4 |
| молчание / не разобрано | 0 | 0 |
| в ответе есть расчёт ожидаемого итога ходов (вероятность × ход − риск) | **1 из 28** | **25 из 28** |

Доля решений почти не изменилась: этот прокси и так решителен. Изменился способ решать. На промптах 5.4.3 модель
сравнивает ходы по ожидаемому итогу в % (п.7 доктрины) и ставит засаду числом там, где раньше описывала условие
словами. Например, в «середине боковика» 5.4.2 ответил ЖДЁМ, а оба входа описал в заметке: «лонг: закрепление над
304… либо спринг под 296». Позиция в плюсе у сопротивления держится с подтянутым тросом (ДЕРЖАТЬ с числом), а не
«ЖДЁМ» без уровня.

## По ситуациям (решение и уровни, два ответа)

| ситуация | узел | разумно | до (5.4.2) | после (5.4.3) |
|---|---|---|---|---|
| Боковик 296–304, цена 300 в середине; совет дал WAIT «ждём пробоя 304» | перепроверка | ждать можно | засада КУПИТЬ откат 296.6 ×2 | засада КУПИТЬ откат 296.8 / 297.0 |
| Нижний край боковика 296.4, покупатель в ленте | перепроверка | действие | КУПИТЬ сейчас ×2 | КУПИТЬ сейчас ×2 |
| Пробой 304 с объёмом ×2.5, удержание 20 мин | перепроверка | действие | КУПИТЬ сейчас ×2 | КУПИТЬ сейчас ×2 |
| Ложный пробой 304.8 → 302.9, продавец | перепроверка | действие | ПРОДАТЬ сейчас ×2 | ПРОДАТЬ сейчас ×2 |
| Тренд вниз, отката к 302 для SELL нет | перепроверка | действие | ПРОДАТЬ сейчас ×2 | ПРОДАТЬ сейчас ×2 |
| Внеплановое снижение ставки, +1.6 % за 10 мин | перепроверка | действие | КУПИТЬ сейчас ×2 | КУПИТЬ сейчас ×2 |
| Мёртвый рынок (контроль) | перепроверка | ждать можно | засада КУПИТЬ 296.6; **ЖДЁМ** | засада КУПИТЬ 299.5; засада КУПИТЬ 296.8 |
| Лонг +1.2 % у сопротивления 302 | перепроверка в позиции | выход можно | ЖДЁМ ×2 (стоп 299.4) | ДЕРЖАТЬ ×2, трос вверх 300.6 / 299.4 |
| Лонг −0.5 %, продавец давит к триггеру | перепроверка в позиции | выход можно | ПЕРЕВЕРНУТЬ; ЗАКРЫТЬ | ПЕРЕВЕРНУТЬ ×2 |
| Шорт +1.2 %, тренд идёт | перепроверка в позиции | добор можно | ЖДЁМ ×2 | ДЕРЖАТЬ ×2, трос вниз 301.0 / 301.2 |
| Дверь: приказ BUY «сейчас» 12 мин назад | дверь | действие | ВОЙТИ ×2 | ВОЙТИ ×2 |
| Дверь: засада «прорыв 304» достигнута | дверь | действие | ВОЙТИ ×2 | ВОЙТИ ×2 (стоп подтянут 302.9 / 303.1) |
| Прибыль +1.8 %, рывок выдыхается | мысль о прибыли | выход можно | ВЫЙТИ; ВЫЙТИ_И_ПЕРЕЗАЙТИ | ВЫЙТИ_И_ПЕРЕЗАЙТИ ×2 (откат 302.1 / 301.8) |
| Спорные сигналы (спринг против продавца) | вердикт | ждать можно | BUY ×2 | BUY ×2 (частью сейчас, частью засадой) |

«×2» — оба ответа одинаковы по решению. «Засада» — вход у уровня (entry_kind «откат»), а не по рынку. Засада
перепроверки бьётся без второго вопроса у двери, пока ей не больше `PYTHIA_ENTRY_FRESH_SEC`.

## Что это значит

- **Перекос к «вне рынка» из промптов ушёл, «входит не глядя» не вернулся.** В каждом входе есть стоп
  (invalidation). В контрольных ситуациях, где можно было ждать (середина боковика, мёртвый рынок), новая версия
  ставит засады у краёв диапазона, а не покупает по рынку. Это и есть «диапазон — тоже рынок» из доктрины.
- **Добор при идущем тренде** (шорт +1.2 %) ни одна версия не выбрала: модель опирается на поддержку MX 2850 рядом.
  Это решение по данным, а не перекос промпта.
- **Проверить на DeepSeek.** Решает ли DeepSeek так же, покажет только его прогон стенда. Если после 5.4.3 он всё ещё
  отвечает ЖДЁМ там, где агент Claude действует, — это его собственный крен. Тогда следующий шаг — поле `ev` в JSON
  и повтор перепроверки, если выбран ход не с наибольшим итогом (исследования: DeLLMa, TradingAgents).
