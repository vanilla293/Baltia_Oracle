# СТРУКТУРА ПРОЕКТА «ПИФИЯ» — из чего он состоит

Документ для нового агента: только устройство, без оценок. Что где лежит, что
делает каждый модуль, как данные текут между ними, какие форматы и точки входа.

## 1. Что это за проект

**ПИФИЯ** — локальный торговый терминал для Мосбиржи (акции и фьючерсы FORTS).
Сервер на Python (FastAPI) отдаёт один HTML-файл панели, собирает новости и
рыночные данные, гоняет их через ИИ DeepSeek и исполняет сделки через брокера
Tinkoff. Владелец использует его как полигон для исследования возможностей ИИ
при разных промптах и условиях.

Две эпохи в одном репозитории:

- **4.x «Оракул // Пифия»** (июль–август 2026): конвейер «досье инструмента →
  аналитик → критик → синтез → шифровка» с большими персонами-промптами, оракул-свод
  голосов, автопилот и ИИ-пилот, слои неба (астро, эфир), микроструктура стакана,
  нелинейная динамика (бифуркации, Курамото, Хоукс), лаборатория стендов. Тёмный
  интерфейс «терминал». Сегодня — **библиотека** для v5 и история.
- **5.0 «Совет»** (18.09.2026): новый алгоритм ИИ на двух моделях (FLASH — механика,
  PRO — совет), четыре шага (новости → совет, взгляд человека, миссия, журнал) плюс
  дозор, новый светлый интерфейс. Использует модули 4.x для данных биржи, неба и
  исполнения.

## 3. Запуск, конфигурация, данные

**Запуск.** `start.bat` (Windows, только ASCII внутри) и `start.sh` (Linux/macOS):
проверка Python 3.10+ (предпочитает `py -3`, ловит заглушку Microsoft Store) →
`.venv` (битый пересоздаётся) → зависимости СНАЧАЛА (вывод на экран и в
`data/install.log`, проверка импорта, до трёх повторов, затем пересоздание `.venv`)
→ меню режима: 1 обычный, 2 сухой (`PYTHIA_DRY=1`, по умолчанию), 3 демо
(`PYTHIA_MOCK_AI=1 PYTHIA_MOCK_TINKOFF=1 PYTHIA_DRY=1`) → `backend.fetch_data`
(эфемериды ~32 МБ один раз, не в демо) → проверка `from backend import server` →
предупреждение о занятом порте → `uvicorn backend.server:app` на `PORT` (8799) и
браузер. Предупреждает, если папка лежит в OneDrive/Яндекс/Google Диске (облако
ломает `.venv` во время установки). `requirements.txt` — диапазоны версий
(fastapi ≥0.115, pydantic ≥2.10 и т.д.), чтобы вставали готовые колёса под свежие
Python. Ручной запуск:
`RS_NO_BROWSER=1 python3 -m uvicorn backend.server:app --port 8799`.

**Конфигурация** — `backend/config.py`. Приоритет: `data/config_user.json` →
переменная окружения → значение по умолчанию. Функции: `get/get_int/get_float/
get_bool`, `set_many`, пул ключей DeepSeek (`deepseek_keys`, `set_deepseek_keys`,
`pick_pool_key`, `failover_key`, `mark_key_unhealthy`), ключи по инструментам
(`INSTRUMENT_KEYS`, `key_for`), `wipe_keys`, `public_snapshot`, `_refresh` (пересчёт
всех `config.X`). Ключевые параметры: `DEEPSEEK_MODEL` (deepseek-v4-pro),
`DEEPSEEK_MODEL_FAST` (deepseek-flash), `DEEPSEEK_BASE_URL`, `AI_REASONING_EFFORT`
(пусто = не шлём = умолчание API high; режима auto у DeepSeek нет), `AI_THINKING`, `AI_MAX_TOKENS` (393216 — явный максимум модели), `TINKOFF_TOKEN`, `HOST/PORT`, `NEWS_DAYS`,
`NEWS_CACHE_SEC`, `RESET_ON_START/WIPE_KEYS_ON_START/WIPE_ON_EXIT` (в v5 выключены:

событийных перепроверок), `PYTHIA_AFTER_CLOSE_SEC` (900 — остыть после закрытия),
`PYTHIA_QUIET_SEC` (900 — тишина после входа), `PYTHIA_FLIP_QUIET_SEC` (1200 — защита от
переворота), `PYTHIA_COUNCIL_GAP_SEC` (1800 — окно полного совета); 5.4.1 «трезвый пилот»: `PYTHIA_EXCHANGE_STOP` (0 —
стопы только в программе, стоп-заявок на бирже нет; 1 — трос на бирже), `PYTHIA_MONEY_MODEL` (pro|flash — модель узлов у
денег), `PYTHIA_ENTRY_CHECK` (1) и `PYTHIA_ENTRY_CHECK_COOL_SEC` (300 — проверка входа у двери), `PYTHIA_PROFIT_THINK` (1),
`PYTHIA_PROFIT_THINK_PCT` (60), `PYTHIA_PROFIT_THINK_MIN_PCT` (1.0), `PYTHIA_PROFIT_THINK_COOL_SEC` (900 — мысль о прибыли);
первые два меняются из панели «Ключи» (`POST /api/v5/keys` → `set_many`, живые через `config.X`). Файл содержит длинный
changelog 4.x в комментариях.

**Переменные окружения только через env:** `PYTHIA_DRY` (брокер в dry),

**`data/`** (gitignored): `config_user.json` (ключи, права 0600), `pythia_v5.db`
(SQLite v5), `pythia.db` (SQLite 4.x: последние разборы и чат), `pythia_v5_mock.db`
(база демо), `trader_audit.jsonl` (аудит всех ордер-интентов брокера),
`aipilot_state.json` (позиция пилота для рестарта + секция `pilot`: дедуп/пейсинг прокола сканера, фаза 3), `russian_trusted.pem` (CA
Минцифры, качается сама), `mathieu_periods.json` (константы лаборатории).

### 4.6 Поток данных v5 (сквозной)
RSS → `news_raw` → FLASH отбор → `news_ai` (по одной) → потоки → цены MOEX + астро →
PRO анализ → критика → вердикт → итог-JSON → карточки тикеров → `council_runs`.
Текст человека → FLASH сжатие → PRO (итог + взгляд) → `council_runs(human)`.
Дозор → новые новости → разметка → impact → `watch_notes` → (severity ≥ 75) миссия.
Миссия → `market_ctx.build` → PRO анализ/критика/вердикт → exec → `MissionPilot`
(тик 1.5 с: цена и стакан Tinkoff → засада/вход/трос/тейк/дозор маржи → каждые 30
мин `_review` → закрытие → `trades` → `council_again`). Панель: `/api/v5/state`
каждые 5 с, `/api/v5/mission/status` каждые 3 с, `/ws/events` для стрима.
