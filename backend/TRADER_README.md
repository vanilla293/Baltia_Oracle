# ПИФИЯ-ХИЩНИК — торговый бот (стадия 1: спина + мозг)

Двухуровневая архитектура из txt: **Аналитик** (Пифия-мозг, раз в час, задаёт
вектор) + **Фармила** (исполнитель в стакане). Здесь заложены три несущих
модуля. Остальное (Аналитик-директива, радар, оркестратор-петля, пульт) —
следующая стадия.

## Безопасность — прочитай первым

Реальные ордера двигают реальные деньги — это необратимо. Поэтому:

- **По умолчанию режим `dry`** (сухой прогон): ордер считается и пишется в
  журнал, но В СЕТЬ НЕ УХОДИТ. Так бот стартует всегда.
- **Песочница `sandbox`**: виртуальные деньги, реальный рынок и стакан Tinkoff.
  Обкатывай Хищника тут, пока он не начнёт стабильно забирать.
- **Боевой `real`** вооружается ТОЛЬКО двойным рубильником:
  переменная окружения `TRADER_ARM_REAL=1` И совпадающий `TRADER_ARM_TOKEN`.
  Нет обоих → брокер молча откатывается в `dry`. Это инвариант: реал не
  включится случайно.
- **Killswitch**: дневной лимит потерь (−6% депозита по умолчанию) и серия
  убытков (3 подряд) аппаратно блокируют торговлю до следующего расчёта
  Аналитика. Никакого «отыгрывания».
- **Размер позиции — от РИСКА и стопа, а не «на всю сумму»**. «На всю котлету»
  и «устойчивость к тряскам» — противоположности; агрессия достигается
  дробным входом «Капкан», а не плечом на всё.

⚫ Это управление риском, НЕ обещание прибыли. Скальпинг на плече — место, где
большинство теряет депозит. Рынок не предсказуем. 18+.

## Модули

| файл | роль | самотест |
|---|---|---|
| `trader_risk.py` | размер от риска, «Капкан» (дробный вход), спред-guard, killswitch | **прогнан у ассистента — зелёный** |
| `trader_strategy.py` | Машина состояний Фармилы (Запал→Разведка→Капкан→Трейлинг) + триггеры выхода | написан, синтаксис ок — **запусти сам** |
| `trader_broker.py` | руки: ордера через Tinkoff (dry/sandbox/real), портфель, паника, аудит-лог | написан, синтаксис ок — **запусти сам** |

Ассистент-песочница блокирует ИСПОЛНЕНИЕ торгового кода (защита вокруг
авто-трейдинга), поэтому broker и strategy проверены только синтаксисом.
Их самотесты написаны — прогони их у себя:

```bash
cd backend
python3 trader_risk.py       # → self-test OK (математика риска)
python3 trader_strategy.py   # → self-test OK (жизненный цикл сделки на синтетике)
python3 trader_broker.py     # → self-test OK (dry не шлёт, real за двойным рубильником)
```

## Обкатка в песочнице (когда соберём петлю)

1. Заведи Tinkoff-токен с доступом к песочнице, введи в интерфейсе.
2. Запусти бота в режиме `sandbox` — он откроет виртуальный счёт, пополнит
   виртуалом, и Хищник начнёт фармить Si/CNY на реальном стакане без риска.
3. Смотри `data/trader_audit.jsonl` — там каждое решение и ордер.
4. Когда статистика песочницы устроит — только тогда взводи `real` двойным
   рубильником. Начни с 1% риска на сделку.

- **Аналитик-директива**: раз в час reactor_sky + aether + maya_scan + DeepSeek
  → LONG/SHORT/FLAT + режим (тренд/флет/бифуркация) — якорь для Фармилы.
- **Радар**: лёгкий скан Si/CNY на всплеск объёма/ускорение (бесплатно, часто).
- **Оркестратор**: петля радар→аналитик→Фармила→брокер с killswitch и
  read-only при рассинхроне API.
- **Пульт**: таб на фронте — статус, позиции, аудит, кнопка ПАНИКА, рубильник
  режима.
- **Поводырь-спот, VPIN, скорость отмен, VWAP-магнит, Херст, солитон** —
  фичи из txt, подаются в feats Машины состояний.
