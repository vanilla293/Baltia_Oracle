1. ВОЛНА Ψ (небесная стоячая волна) 🟡 на 🔵-эфемеридах

4. ЭНЕРГИЯ ХОДА (лента) 🔵

CWT Морле ω₀=6: λ = 4π/(ω₀+√(2+ω₀²)); выпрямление |W|²/s (Liu 2007) конус влияния (канон Торренса–Компо): доверен период P ≤ λ·t_края/√2 ≈ 0.73·t e(t) = средняя доверенная мощность бара e01 = средний ранг e в окне (связки — average rank, v2.7.2) пол шума: e < 2%·max(e) → 0; мёртвое окно (σ≈0) → None (не ранг!) доминанта окна: argmax средней доверенной мощности шкалы, P ≤ span/2 пучности ⚡: ЛОКАЛЬНЫЕ максимумы e01 ≥ 0.7; правый край — НЕ пучность (v3.0.0)

Яркость ленты = e01 (сила), цвет = терциль периода доминирующей шкалы бара (голубой быстрый / янтарный средний / фиолетовый медленный). Чип ⚡ показывает e01 сейчас и доверие краю (доля доверенных глубин): ⚡0.93·дов 0.06 значит «ранг высок, но конус у свежего бара видит только быстрые глубины — вес суждению меньше».

6. ТАЙМИНГ СКАЛЬПА 🟡 на 🔵-геометрии

7. ВЕРСОР ШТЕЙНМЕЦА–ДОЛЛАРДА 🔵 LC-осциллятор 🟡 слова

x = Ψ − ⟨Ψ⟩; ω̄ = median(ω>0), ω — мгновенная частота (медфильтр 9) E_d = ½·ω̄²·x² «диэлектрик» — натяжение (пружина сжата) M_k = ½·(dx/dt)² «магнетизм» — разрядка; нормировка: max(E_d+M_k)=1 натяжение («пробой зреет»): E_d ≥ P70 ∧ M_k < 0.15 ВЫДЕРЖКОЙ ≥ ¼ периода несущей (кап: треть окна, v2.7.2) — фаза Гильберта на плато НЕ замирает, потому детектор по выдержке

8. СВЕТОФОР ПОЛЯ ⚑ 🟡 сборка открытыми весами

9. СТАРШИЕ КЛЮЧИ 🟡 на честной геометрии 🔵

Полость Гребенникова (изопериметрия Штейнера, сота Хейлза 2001): Q = √(n/4) · e^{−mean(d/3)²} · (1+var(d)/4)⁻¹ · min(1, IQ/IQ_правильного) IQ = 4πS/P²; d — орбис-отклонения рёбер; Крест 1.0 > Прямоуг .928 > Трин .866 > Тау .772 Аккорд Кили (механика — консонанс Гельмгольца 1863): c_ij = max_r (nm)^{−½}·exp(−((q−r)/(r·σ₀√(nm)))²), q=|vᵢ/vⱼ|, σ₀=0.004 r ∈ {2:1, 3:2, 4:3, 5:4, 6:5, 5:3, 8:5}; противоход (vᵢvⱼ<0) рвёт аккорд аккорд = связка ≥3 тел, c ≥ 0.10; R = Σ c·√(EᵢEⱼ); без аккорда R = 0 ровно

12. EBS ЭЛЕРСА — рельс/качели 🔵 фильтры 🟡 пороги

hp[t] = ½(1+a)(c[t]−c[t−1]) + a·hp[t−1], a = (1−sin θ)/cos θ, θ = 2π/40 SuperSmoother(10): a1=e^{−1.414π/10}, b1=2a1·cos(1.414π/10); c2=b1, c3=−a1², c1=1−c2−c3 Wave = (filt+filt₁+filt₂)/3; Pwr = (filt²+filt₁²+filt₂²)/3; EBS = Wave/√Pwr ∈ [−1,1] РЕЛЬС = однознаковая выдержка ≥18 баров за ±0.85 (находка веера: на чистом цикле EBS касается рельс на каждом горбе — мгновенный порог лжёт); прогрев max(100, 2·40) баров → None; только закрытые бары

Ehlers, «Cycle Analytics for Traders» 2013, гл. 12. HP нарочно однополюсный — тренд просачивается, это и есть детектор режима. У Элерса градусы — здесь радианы.

20 · АУДИТ №3 — v3.1.0 «безжалостная шлифовка»

20.1 AR-хвост Гильберта (правый край чист). Зеркальная добивка отражала будущее как прошлое задом наперёд — наклон фазы на секунде «сейчас» ломался о складку. Теперь хвост = AR(4)-продолжение последних баров (для тона — точное), кроссфейдом приводимое к зеркалу у шва кольца. Ядро H[cos]≈sin с точностью 0.009; наклон фазы края 0.3932 при истине 0.3927.

20.2 Фильтр Бедросяна. Гильберт честен только на узкой полосе; сырая цена — фрактальный шум. Фаза цены теперь считается в полосе ±1 октава вокруг доминанты волны Ψ (rfft-маска). Тест: PLV зашумлённой цены 0.84→0.999.

20.3 Мгновенное зеркало (v3.1.1 — по слову стенда). M(t)=cos(φp−φw) по сырым фазам, сглаженный за 8 баров ядра; гистерезис вкл < −0.5 / выкл > −0.25. Полоса Бедросяна для зеркала НЕ используется: она вырезает трендовую компоненту, по которой связь и судится (на BRU6 полосная фаза давала +0.18 при сырой −0.95 — зеркало ложно слетало, проекция переворачивалась). Полоса остаётся для PLV и W. Два зеркала: ВПЕРЁД — мгновенная фаза; НАЗАД (наложение прошлого) — фаза окна по corr. Разошлись — чип «фаза ⇅ у „сейчас“»: излом на «сейчас» и есть момент переворота.

20.4 Индекс обмотки W. W=(Δ(φp−φw))/2π по развёрнутым фазам за окно, в оборотах. PLV слеп к сдвигу на целый круг; W видит скрученную пружину: перегрев (+) / пружина (−); разрядка отматывает к нулю.

20.5 Трубка вероятности. Проекция — не линия-приговор: σ=½ полосы неуверенности; коридор 68% (±σ) ярче, 99% (±2.3σ) тише. PLV→1 сжимает трубку в луч, хаос раздувает в облако.

20.6 Склейка времени (матрёшка). Фазы масштабов 1×/4×/12× интерполируются на быструю сетку; r01 — согласие косинусов за хвост. Спор масштабов придавливает створы множителем 0.6+0.4·r01.

20.7 Чириков: окна хаоса. Перекрытие зон соседних узлов K=Σσ/зазор ≥ 1 — динамический хаос: уровни ненадёжны, створ внутри окна помечен ⌖⚡.

20.8 Хёрст-топология полостей. H<0.5 — полость «вакуум-магнит» (возврат втянет), H>0.5 — «броня» (опора/крышка). Скаляр глубинного эфира — на чистой 3D-сфере (Θ=acos(u·u), ложный штраф широты убит). В аккордах — тритон-мосты 36:25 и Φ-каналы КАМ (идентификация 2%).

20.9 Стенд направления (v3.1.1). Walk-forward без подглядывания: 30 якорей × 4 инструмента (BRU6, SBER, GAZP, LKOH), 5м, горизонты 1ч/3ч, факт — следующие бары. Итог: зеркало по сырой мгновенной фазе — знак 1ч 0.50 / 3ч 0.49 против 0.45/0.44 у оконной corr (v3.0); наложение прошлого лучше у corr-фазы (0.30 против 0.25) — поэтому прошлое рисуется в ней. ЧЕСТНО: попадание по знаку на 1–3 часах — около монеты; проекция — линза состояния среды, не направленный сигнал и не торговая рекомендация. Стенд же поймал и вылечил расходимость AR-хвоста на живых ценах (ранний обрыв → откат на зеркало).

Отклонено владельцем: оцифровка оператора. Честно невозможно на свечах ISS: энтропия объёма по тикам (нет ленты). Механика — факт; слова школы — язык; выбор за человеком.
