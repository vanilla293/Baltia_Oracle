ПИФИЯ 3.17.0 «ХИЩНИК» — ЗАПУСК (CRU6, всё из панели)
=====================================================

ГЛАВНОЕ ИЗМЕНЕНИЕ: второй терминал больше НЕ нужен.
Запустил разбор CRU6 в панели → ИИ отработал → АВТОПИЛОТ СТАРТУЕТ САМ.

--------------------------------------------------------------------
ШАГ 0 — ПРОВЕРКА (2 минуты, обязательно один раз)
--------------------------------------------------------------------
В папке pythia:

    python -m py_compile backend/*.py
    python backend/decision.py        # decision self-test OK
    python backend/limits.py          # limits self-test OK
    python backend/trader_risk.py     # trader_risk self-test OK
    python backend/microstructure.py  # microstructure self-test OK

Любая ошибка — не запускать боевой, прислать текст ошибки в чат.
(Эта сборка собиралась в песочнице, где мне блокировали запуск торгового
кода, поэтому проверка на твоей машине обязательна.)

--------------------------------------------------------------------
ШАГ 1 — ЗАПУСК ПАНЕЛИ
--------------------------------------------------------------------
Обычным лаунчером (как ты уже делал) → откроется http://localhost:8799
В логе должно быть: ОРАКУЛ // ПИФИЯ v3.17.0

Про SSL: при первом обращении к Тинькофф бот сам скачает сертификаты
Минцифры → в логе «CA Минцифры скачаны». Если раньше сыпалось
CERTIFICATE_VERIFY_FAILED — теперь пройдёт. Если всё равно сыплется:
антивирус (Касперский/Dr.Web) перехватывает HTTPS — выключи «проверку
защищённых соединений» для python.exe.

--------------------------------------------------------------------
ШАГ 2 — КЛЮЧИ (в интерфейсе, не в терминале)
--------------------------------------------------------------------
Ключ Тинькофф (с правом торговли, на счёт с деньгами) и ключ DeepSeek
вводишь прямо в панели. Бот их теперь ВИДИТ (в 3.16 читал только env —
это была недоработка, закрыта).

--------------------------------------------------------------------
ШАГ 3 — СУХОЙ ПРОГОН (ордера НЕ уходят)
--------------------------------------------------------------------
Просто запусти разбор CRU6 в панели. Когда ИИ закончит — в блоке ВАКУУМ
появится карточка:

    🤖 АВТОПИЛОТ: сухой прогон (ордера в лог)

Петля живёт: стакан, рентген «кто в стакане», ИИ-bias, решения свода —
всё считается и пишется, но в биржу ордера НЕ отправляются.
Посмотри час на открытом рынке — решения должны быть осмысленными.

--------------------------------------------------------------------
ШАГ 4 — БОЕВОЙ (реальные деньги, без кнопок одобрения)
--------------------------------------------------------------------
Закрой панель. Открой терминал в папке pythia и задай два рубильника,
потом запусти лаунчер ИЗ ЭТОГО ЖЕ окна:

    set TRADER_ARM_REAL=1
    set TRADER_ARM_TOKEN=любая_твоя_фраза
    (затем твой обычный запуск панели)

Теперь после разбора карточка станет красной:

    🤖 АВТОПИЛОТ: БОЕВОЙ (реальные деньги)

Первый час после открытия рынка — наблюдение (считает, не торгует),
в карточке видно «наблюдение ещё N мин». Отключить: set PYTHIA_OBSERVE_MIN=0

--------------------------------------------------------------------
УПРАВЛЕНИЕ (кнопки в карточке автопилота)
--------------------------------------------------------------------
    ЗАПУСТИТЬ — поднять петлю руками, без разбора
    СТОП      — мягко остановить петлю (позиция остаётся)
    ПАНИКА    — закрыть позиции немедленно и встать
Автостарт после разбора отключается: set PYTHIA_AUTOSTART=0

--------------------------------------------------------------------
ЧТО ВНУТРИ РЕШЕНИЯ (тик ~1.5 с)
--------------------------------------------------------------------
стакан+лента → рентген (OBI/CVD/VPIN/отмены/Хёрст/Казимир: ММ / Кит /
ловушка / инфаркт) → ИИ-шифратор DeepSeek (раз в час и при смене актора)
→ СВОД (Казимир-прострел · За-Китом · Фейд-стоп-ханта · Возврат-к-VWAP ·
Против-иллюзии) → комиссия 0.02%/сторона (0.04% круг) по масштабу хода →
размер (25% база, скачок→макс, «не даёт лот — набираем до макса») →
лимитная тактика (лимит только у точки, импульс → ближайший, плиты,
призраки) → ордер.
В позиции: играем ПОКА НЕ ПОВЕРНЁТСЯ (выход по CVD-флип + актор);
защита стопа двухфакторная (тенденция + Хёрст), допуск до 0.5% —
мелкий буфер ММ не пережуёт, глубже 0.5% — выход всегда.

ТОРМОЗА (всегда): killswitch −6%/день или 3 убытка подряд · инфаркт
спреда → выход и запрет входов · ПАНИКА.

⚫ Боевой режим — реальные деньги на плече без подтверждений: включаешь
его ты рубильником. Не обещание прибыли. Рынок не предсказуем. 18+.
Токены в репозиторий не коммить.
