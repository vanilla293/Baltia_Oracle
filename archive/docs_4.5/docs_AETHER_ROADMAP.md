## 1. Линия Элерса (Габор→Гильберт в трейдинге)

### Формулы
## 1. Volume Profile из OHLCV (биннинг + POC + Value Area)

**Сетка цен.** Шаг h = тик инструмента (фьючерсы) или h = (max(H)−min(L))/B при B≈50–100 бинов на сессию. Границы: `edges = np.arange(p_min, p_max + h, h)`, центры `centers = (edges[:-1]+edges[1:])/2`.

**Распределение объёма бара — конвенции (важно выбрать одну и зафиксировать):**
- (a) **Равномерно по H–L** (дефолт TradingView/большинства платформ): объём бара V_i размазывается пропорционально перекрытию бина с [L_i, H_i]. Это честнее всего без тиков.
- (b) **Всё в бин close** — грубее, профиль «зубастый», но иногда используется для «профиля закрытий».
- (c) Взвешивание к close/телу (треугольное ядро) — экзотика, стандартом не является.

```python
prof = np.zeros(B)
for Hi, Li, Vi in bars:                      # бары младшего ТФ (лучше 1m)
    if Hi == Li:
        prof[np.searchsorted(edges, Hi, 'right')-1] += Vi
        continue
    ov = np.clip(np.minimum(edges[1:], Hi) - np.maximum(edges[:-1], Li), 0, None)
    prof += Vi * ov / (Hi - Li)              # конвенция (a)
```

**POC:** `poc = np.argmax(prof)`; цена — `centers[poc]`. Тай-брейк по Стейдлмайеру (для TPO): из равных берётся уровень, ближайший к середине диапазона сессии.

**Value Area (цель 70% объёма; 68.27% = ровно 1σ гаусса — 70 % это округление CBOT).** Канонический алгоритм CBOT — расширение от POC **парами строк**: сравнивается сумма ДВУХ бинов сверху против суммы ДВУХ бинов снизу, добавляется большая пара; повторять до достижения цели. Вариант «по одной строке» (сравнение одиночных соседних бинов) тоже распространён — даёт чуть иные VAH/VAL.

```python
target = 0.70 * prof.sum()
lo = hi = poc; cum = prof[poc]
while cum < target and (lo > 0 or hi < B-1):
    up = prof[hi+1:hi+3].sum() if hi < B-1 else -np.inf
    dn = prof[max(lo-2,0):lo].sum() if lo > 0 else -np.inf
    if up >= dn: cum += up; hi = min(hi+2, B-1)
    else:        cum += dn; lo = max(lo-2, 0)
VAL, VAH = centers[lo], centers[hi]         # парная версия может слегка «перелить» за 70% — это принятая условность
```

**Developing POC/VAH/VAL:** после закрытия каждого бара t профиль пересчитывается по барам сессии [0..t] и снимаются dPOC_t, dVAH_t, dVAL_t → три линии-серии во времени. Инкрементально: `prof += вклад бара t` (O(B) на бар), argmax и расширение VA заново (B мало — дёшево).

## 2. VSA (Том Уильямс) — механизируемые сигналы из OHLCV

Базовые величины: спред `S = H - L`; позиция закрытия `cp = (C - L)/(H - L)` (при S=0 → None, не 0.5); up-бар `C_t > C_{t-1}`, down-бар `C_t < C_{t-1}`; скользящие `Vm = SMA(V, 20)`, `Sm = SMA(S, 20)`; относительные `rv = V/Vm`, `rs = S/Sm`.

У Уильямса правила КАЧЕСТВЕННЫЕ; числовые пороги ниже — рабочая формализация (пороги — прокси, честно пометить):

- **No Demand** (медвежий в контексте слабости): up-бар И rs < 0.7 И cp ≤ 0.5 И V_t < V_{t-1} И V_t < V_{t-2}. Подтверждение: следующий бар down.
- **No Supply** (бычий в контексте силы): down-бар И rs < 0.7 И cp ≥ 0.5 И V_t < V_{t-1} И V_t < V_{t-2}. Подтверждение: следующий бар up.
- **Stopping Volume** (после серии падений): down-бар И rv ≥ 1.5–2 И cp ≥ 0.5 (закрытие в верхней половине — покупатель поглотил) И близость к локальному минимуму `L_t <= min(L[t-k:t])`, k≈10–20.
- **Selling/Buying Climax:** rv ≥ 2 И rs ≥ 1.5 (широчайший спред) И новый экстремум k баров И закрытие оторвано от экстремума (SC: cp ≥ 0.3; BC: cp ≤ 0.7).
- **Upthrust** (ложный пробой вверх): H_t > max(H[t-k:t]) И cp ≤ 0.25 И rs ≥ 1 И rv ≥ 1. Зеркально — spring/shakeout вниз.
- **Test** (проверка предложения): down-бар, заходящий в зону недавнего высокого объёма, rv ≤ 0.7, rs < 0.7, cp ≥ 0.5.
- **«Усилие против результата» — непрерывная метрика** (лучше бинарных флагов): `effort = zscore(V, 20)`, `result = zscore(|C_t - C_{t-1}|, 20)` (или zscore(S)); дивергенция `D = effort - result`. D >> 0 — усилие без результата = поглощение/absorption. Альтернатива (подход neurotrader888/VSAIndicator): скользящая OLS-регрессия S на V, аномалия = стандартизированный остаток.
- **Absorption без стакана:** rv ≥ 2 И |C_t − C_{t-1}| < 0.25·ATR(14) И маленькое тело |C−O|/S < 0.3.

НЕ вычислимо честно из OHLCV: реальное поглощение лимитками в стакане, айсберги, дельта по bid/ask — это только тики/DOM.

## 3. VWAP + полосы σ (якорь = сессия)

`tp = (H + L + C)/3` (типичная цена бара).
`VWAP_t = Σ_{i≤t}(tp_i·V_i) / Σ_{i≤t}(V_i)` — кумулятивно ВНУТРИ сессии, сброс на якоре (открытие сессии/дня; anchored-вариант — от свинг-экстремума).
Дисперсия — взвешенная по объёму (популяционная): `σ_t² = Σ(V_i·tp_i²)/Σ(V_i) − VWAP_t²`; полосы `VWAP ± k·σ_t`, k = 1, 2 (3 — редко).

```python
g = df.groupby(session_id)
pv  = (df.tp * df.V).groupby(session_id).cumsum()
vv  = df.V.groupby(session_id).cumsum()
vwap = pv / vv
var  = (df.V * df.tp**2).groupby(session_id).cumsum() / vv - vwap**2
sd   = np.sqrt(np.clip(var, 0, None))    # clip: E[x²]−E[x]² может дать −1e-12
```
Числовая устойчивость: считать в float64 и предварительно вычесть из цен опорную константу (открытие сессии), иначе на больших ценах катастрофическое сокращение.

## 4. Дельта-прокси без ленты

`buyV = V·cp`, `sellV = V·(1−cp)`, `delta = V·(2·cp − 1) = V·((C−L)−(H−C))/(H−L)`; H=L → delta = 0 (или None). Кумулятив: `CVD_t = Σ delta` со сбросом на сессии.
Точность резко растёт, если считать дельту на 1m-барах и агрегировать суммой в 5m — приближение к тиковой дельте заметно честнее, чем cp по самому 5m-бару.
Альтернативный прокси: Balance of Power `(C−O)/(H−L)` (Игорь Лившин) — по телу, не по закрытию; тик-правило (Lee–Ready) требует тиков — недоступно.

### Скальперу
Скальперу на 5-минутках рисовать (по убыванию ценности):

1. **Профиль ВЧЕРАШНЕЙ сессии — три горизонтальные линии:** POC, VAH, VAL. Плюс «голые» (naked/untested) POC прошлых дней, до которых цена ещё не дотянулась — магниты. Профиль строить из 1m-баров (конвенция равномерного H–L), отображать на 5m-чарте.

2. **Развивающийся профиль текущей сессии:** гистограмма справа + линия dPOC, обновляемая на закрытии каждого 5m-бара. Миграция dPOC вверх/вниз — фильтр направления дня; плоский dPOC = баланс, ротация.

3. **Сессионный VWAP + полосы ±1σ, ±2σ.** В балансе: цена у ±2σ → возврат к VWAP; в тренде: откаты к VWAP/±1σ — зоны продолжения. Наклон VWAP = режим.

4. **VSA-маркеры на свечах** (глиф/цвет): ND, NS, SV, климакс, апраст, тест. Ценность только в КОНФЛЮЭНСЕ с уровнями: No Demand у VAH или верхней ±2σ → триггер шорта к POC/VWAP; No Supply у VAL/VWAP при растущем dPOC → триггер лонга. Отдельно VSA-флаг без уровня — шум.

5. **Подграфик CVD-прокси** (кумулятивная дельта из 1m, сброс на сессии) + непрерывная метрика D = zscore(V) − zscore(|ΔC|). Дивергенция «цена — новый хай, CVD — нет» + всплеск D = поглощение, предупреждение о развороте.

**Плейбук уровней (Dalton):** открытие ВНУТРИ вчерашней VA → день-ротация, fade краёв VA к POC. Открытие ВНЕ VA и возврат внутрь с удержанием 2 последовательных 5m-закрытий внутри → «правило 80%»: цель — противоположный край VA. Пробой VAH/VAL с ростом объёма и уходом dPOC следом → тренд, не fade.

Технически: бины = тик инструмента (ликвидные фьючерсы) или ~50–100 бинов на дневной диапазон; пересчёт VA на каждом закрытии бара; VWAP/CVD — строго с якорем сессии биржи (для 24h-рынков сессию определить явно).

### Грабли
1. **Профиль из OHLCV ≠ тиковый профиль.** Равномерное размазывание V по H–L — аппроксимация; POC может гулять на ±несколько бинов против профиля по тикам/bid-ask. Смягчение: строить из самого мелкого доступного ТФ (1m), не из 5m. Конвенция «всё в close» ещё грубее.

2. **70% — условность, а не закон.** Это округление 68.27% (1σ нормального распределения), но реальные профили не гауссовы (бимодальные дни, P/b-формы). Парное расширение CBOT может «перелить» за 70%; однострочный вариант даёт другие VAH/VAL. Разные платформы дают разные VA — выбрать одну конвенцию и не менять.

3. **VSA у Уильямса — качественная система.** Числа (0.7·средний спред, 2·средний объём, трети диапазона, SMA-20) в «Master the Markets» отсутствуют — это прокси-формализация из практики индикаторостроения (подтверждено ATAS: «строгих количественных правил нет»). В терминах проекта это честный 🟡: формула стоит на прокси, прокси назвать в note. Absorption/айсберги полноценно видны только в стакане.

4. **Дельта-прокси — эвристика позиции закрытия, не order flow.** Корреляция с тиковой дельтой умеренная: ок для направления и дивергенций, НЕ ок для абсолютных величин. Ломается на доджи и барах с длинными тенями; H=L → 0/None (не выдумывать середину). Агрегация из 1m обязательна, иначе прокси заметно врёт.

5. **«Объём» объёму рознь.** На форекс/CFD volume = число тиков, не контракты — VSA и дельта там стоят на песке. Крипта: объём честный, но пер-биржевой; профиль одной биржи ≠ рынок.

6. **Не торговый сигнал.** Всё выше — контекст и конфлюэнс, статистического эджа сами по себе эти построения не гарантируют; любые пороги перед использованием — бэктест на своём инструменте. По законам школы: финансовый слой — не торговый сигнал, 18+, полюс за человеком.

7. **Сессия — обязательный параметр.** VWAP, VA, CVD без явного якоря сессии не определены; для 24h-рынков (крипта) выбор границы сессии (00:00 UTC / открытие CME / своя) меняет все уровни.

## 2. Толпа: профиль рынка / VSA / VWAP

### Формулы
ВСЕ формулы Элерса в оригинале — в ГРАДУСАХ (EasyLanguage). Ниже переведено в радианы, готово к numpy. Индекс [t-1] = предыдущий закрытый бар. Рекурсивные фильтры — только циклом или scipy.signal.lfilter. Цена по умолчанию: price = (H+L)/2.

=====================================================================
1. HOMODYNE DISCRIMINATOR (Rocket Science for Traders, 2001, гл. 7) — доминантный цикл через Гильберт/квадратуру
=====================================================================
Гильберт-аппроксимация — 7-tap FIR по чётным отводам, с частотной коррекцией от прошлого периода:
  H(x, P) = (0.0962*x[t] + 0.5769*x[t-2] - 0.5769*x[t-4] - 0.0962*x[t-6]) * (0.075*P[t-1] + 0.54)

Полный конвейер (цикл по t, всё инициализировать нулями, P[0]=6):
  smooth[t]    = (4*price[t] + 3*price[t-1] + 2*price[t-2] + price[t-3]) / 10        # WMA-4
  detrender[t] = H(smooth, P)
  Q1[t] = H(detrender, P)          # квадратура (90° сдвиг)
  I1[t] = detrender[t-3]           # in-phase = задержка на 3 бара (центр 7-tap фильтра)
  # поворот фазора ещё на 90° для однобарного дискриминатора:
  jI[t] = H(I1, P);  jQ[t] = H(Q1, P)
  I2[t] = I1[t] - jQ[t];  Q2[t] = Q1[t] + jI[t]
  I2[t] = 0.2*I2[t] + 0.8*I2[t-1];  Q2[t] = 0.2*Q2[t] + 0.8*Q2[t-1]   # EMA(0.2)
  # гомодин: сигнал * комплексно-сопряжённый сигнал бар назад
  Re[t] = I2[t]*I2[t-1] + Q2[t]*Q2[t-1]
  Im[t] = I2[t]*Q2[t-1] - Q2[t]*I2[t-1]
  Re[t] = 0.2*Re[t] + 0.8*Re[t-1];  Im[t] = 0.2*Im[t] + 0.8*Im[t-1]
  if Im[t] != 0 and Re[t] != 0:  P_raw = 2*np.pi / np.arctan(Im[t]/Re[t])   # в оригинале 360/atan_deg
  # ЗАЩИТА ОТ ШУМА — жёсткие клампы (обязательны, без них разнос):
  P_raw = clip(P_raw, 0.67*P[t-1], 1.5*P[t-1])   # не быстрее ±50% за бар
  P_raw = clip(P_raw, 6, 50)                     # рабочая полоса 6..50 баров
  P[t] = 0.2*P_raw + 0.8*P[t-1]                  # EMA(0.2)
  SmoothPeriod[t] = 0.33*P[t] + 0.67*SmoothPeriod[t-1]   # итог: SmoothPeriod = доминантный цикл

=====================================================================
2. AUTOCORRELATION PERIODOGRAM (Cycle Analytics for Traders, 2013; TASC 9/2016 "Measuring Market Cycles") — Элерс в 2013 считает его ЛУЧШЕ гомодина
=====================================================================
Шаг 1. Roofing filter (препроцессинг, см. п.3).
Шаг 2. Автокорреляция Пирсона на каждом лаге L=1..48 в скользящем окне M (avgLength=3, либо M=L при avgLength=0):
  r[L,t] = PearsonCorr( filt[t-M+1..t], filt[t-L-M+1..t-L] )
Шаг 3. ДПФ по автокорреляции для периодов Pd = 10..48:
  cosPart[Pd,t] = Σ_{N=2..48} r[N,t]*cos(2π*N/Pd)
  sinPart[Pd,t] = Σ_{N=2..48} r[N,t]*sin(2π*N/Pd)
  sqSum[Pd,t]   = cosPart² + sinPart²
Шаг 4. Сглаживание мощности: R[Pd,t] = 0.2*sqSum[Pd,t]² + 0.8*R[Pd,t-1]   (возведение в квадрат — контраст пика)
Шаг 5. AGC-нормировка: Pwr[Pd,t] = R[Pd,t] / max_Pd R[Pd,t]   (максимум по всем периодам на баре t)
Шаг 6. Доминантный цикл = центроид спектра по компонентам с Pwr>=0.5:
  DC[t] = Σ Pd*Pwr[Pd,t] / Σ Pwr[Pd,t],  сумма только где Pwr[Pd,t] >= 0.5
Автокорреляция сама давит некоррелированный шум — потому метод устойчивее гомодина.

=====================================================================
3. ROOFING FILTER = HighPass(48) + SuperSmoother(10) (Cycle Analytics; paper "Predictive Indicators for Effective Trading Strategies")
=====================================================================
2-полюсный HP, срез 48 баров (пропускает только циклы КОРОЧЕ 48):
  a = (cos(0.707*2π/48) + sin(0.707*2π/48) - 1) / cos(0.707*2π/48)
  hp[t] = (1-a/2)²*(x[t] - 2x[t-1] + x[t-2]) + 2(1-a)*hp[t-1] - (1-a)²*hp[t-2]
SuperSmoother — 2-полюсный НЧ, критический период 10 баров (режет всё короче ~10):
  a1 = exp(-√2·π/10);  b1 = 2*a1*cos(√2·π/10)
  c2 = b1;  c3 = -a1²;  c1 = 1 - c2 - c3
  filt[t] = c1*(hp[t]+hp[t-1])/2 + c2*filt[t-1] + c3*filt[t-2]
  # lfilter: b=[c1/2, c1/2], a=[1, -c2, -c3]
Итог: полоса пропускания 10..48 баров — "крыша" над всеми дальнейшими расчётами. Убирает и шум, и spectral dilation (рост мощности ~1/f на низких частотах, замусоривающий измерение цикла).

Защита мгновенного периода от шума у Элерса — четыре слоя: (1) roofing до измерения; (2) клампы скорости изменения периода (0.67x..1.5x) и полосы (6..50); (3) двойное EMA-сглаживание (0.2, затем 0.33); (4) в Cybernetic Analysis (2004) — медиана: DeltaPhase = clip(dφ, 0.1, 1.1) рад, DC = 2π/median(DeltaPhase, 5) + 0.5, InstPeriod[t] = 0.33*DC + 0.67*InstPeriod[t-1]. Fisher Transform — НЕ фильтр периода, а нормализатор формы волны (см. п.7).

=====================================================================
4. SINEWAVE INDICATOR (Rocket Science, 2001)
=====================================================================
Период берётся из гомодина (SmoothPeriod). Фаза — корреляция сглаженной цены с синусом/косинусом за ровно один цикл:
  DCPeriod = int(SmoothPeriod + 0.5)
  Real = Σ_{k=0..DCPeriod-1} sin(2π*k/DCPeriod) * smooth[t-k]
  Imag = Σ_{k=0..DCPeriod-1} cos(2π*k/DCPeriod) * smooth[t-k]
  if |Imag| > 0.001: DCPhase = arctan(Real/Imag)      # градусы: atan_deg
  else:              DCPhase = 90°*sign(Real)
  DCPhase += 90°                                       # sin→cos конвенция
  DCPhase += 360°/SmoothPeriod                         # компенсация лага WMA-4 (1 бар)
  if Imag < 0: DCPhase += 180°                         # квадрант
  if DCPhase > 315°: DCPhase -= 360°
  Sine     = sin(DCPhase)
  LeadSine = sin(DCPhase + 45°)                        # опережение на 1/8 цикла
Сигнал (только в cycle mode): LeadSine пересекает Sine вверх у ДНА цикла — лонг; вниз у вершины — шорт. Опережение 45° даёт вход ~на период/8 раньше разворота.

=====================================================================
5. MAMA / FAMA (TASC 9/2001 "MESA Adaptive Moving Averages"; mesasoftware.com/papers/MAMA.pdf)
=====================================================================
I1, Q1 — из того же Гильберт-конвейера, что в п.1. Затем:
  Phase[t] = atan_deg(Q1[t]/I1[t])                     # в градусах!
  DeltaPhase = Phase[t-1] - Phase[t]
  if DeltaPhase < 1: DeltaPhase = 1                    # градус; защита деления и кламп alpha сверху
  alpha = FastLimit / DeltaPhase                       # FastLimit=0.5
  if alpha < SlowLimit: alpha = SlowLimit              # SlowLimit=0.05
  MAMA[t] = alpha*price[t] + (1-alpha)*MAMA[t-1]
  FAMA[t] = 0.5*alpha*MAMA[t] + (1-0.5*alpha)*FAMA[t-1]
Смысл: быстрая фаза (разворот) → alpha→0.5, MAMA липнет к цене; медленная фаза (тренд/дрейф) → alpha→0.05. FAMA — та же EMA с половинным alpha: пара расходится на движении, слипается во флэте. Кросс MAMA/FAMA почти не лагает.
В радианах: DeltaPhase_rad >= π/180, alpha = FastLimit / (DeltaPhase_rad*180/π).

=====================================================================
6. EVEN BETTER SINEWAVE (Cycle Analytics for Traders, 2013, гл. 12)
=====================================================================
Без измерения цикла вообще — модифицированный roofing + жёсткая нормировка на мощность:
  Duration = 40 (в книге; скальперский вариант 36; SSF период 10, вариант 9)
  a = (1 - sin(2π/Duration)) / cos(2π/Duration)
  hp[t] = 0.5*(1+a)*(price[t] - price[t-1]) + a*hp[t-1]      # ОДНОполюсный HP — нарочно оставляет тренд
  filt[t] = c1*(hp[t]+hp[t-1])/2 + c2*filt[t-1] + c3*filt[t-2]   # SuperSmoother(10), коэф. из п.3
  Wave = (filt[t] + filt[t-1] + filt[t-2]) / 3
  Pwr  = (filt[t]² + filt[t-1]² + filt[t-2]²) / 3
  EBS  = Wave / sqrt(Pwr)          # в [-1, +1]
В тренде EBS "прилипает" к +1 или -1 (это ДЕТЕКТОР трендового режима, а не сбой); в цикле — осциллирует. Пороги ±0.85.

=====================================================================
7. FISHER TRANSFORM (Cybernetic Analysis for Stocks and Futures, 2004, гл. 1)
=====================================================================
Нормализатор: делает распределение почти гауссовым → развороты становятся острыми пиками:
  x[t] = 0.33*2*((price[t] - min(price, 10)) / (max(price,10) - min(price,10)) - 0.5) + 0.67*x[t-1]
  x = clip(x, -0.999, 0.999)
  Fish[t] = 0.5*ln((1+x[t])/(1-x[t])) + 0.5*Fish[t-1]
  Сигнал: кросс Fish и Fish[t-1] (trigger).

=====================================================================
8. ХЁРСТ (The Profit Magic of Stock Transaction Timing, 1970; Cyclic Analysis, лекции 1973 / Traders Press 1999)
=====================================================================
Принципы: суммация (цена = Σ циклов + тренд), гармоничность (соседние циклы кратны ~2, иногда 3), синхронность (донья выравниваются, вершины — нет), пропорциональность (амплитуда ~ периоду), номинальность. Номинальная модель: 18л – 9л – 54м – 18м – 40н – 20н – 80д – 40д – 20д – 10д – 5д; интрадей-продолжение той же лестницы: ~1 день – 160м – 80м – 40м.

ОГИБАЮЩИЕ (envelope analysis): центрированная SMA полного периода N (нечётное) уничтожает цикл N и его гармоники, пропускает более длинные:
  c[t] = mean(x[t-(N-1)/2 .. t+(N-1)/2])        # np.convolve(x, ones(N)/N, 'same'); последние N/2 баров не определены — экстраполировать
  полуширина h = скользящий max |median_price - c| за ~один период N (Хёрст рисовал руками "чтобы вместить всё")
  канал: c ± h — ПОСТОЯННОЙ ширины, границы параллельны
Вложенность: каждому циклу — своя огибающая; малый канал катается внутри большого; касание малым каналом границы большого = зона разворота обоих.

FLD (Future Line of Demarcation): медианная цена, сдвинутая ВПЕРЁД на полпериода:
  fld[t + shift] = (H[t] + L[t]) / 2,  shift = round(N/2) + 1   # (+1 — конвенция Sentient Trader; у Хёрста "half span")
  numpy: fld = np.full(len(x)+shift, nan); fld[shift:] = median_price   # будущий хвост FLD известен уже сейчас
ПОЛУПЕРИОДНАЯ ЦЕЛЬ: цена пересекла FLD → пройдена ровно половина хода полуцикла:
  target = 2*P_cross - P_extreme
  (P_extreme — цена последнего дна цикла при кроссе вверх / вершины при кроссе вниз; P_cross — цена в точке пересечения). Пример: дно 100, кросс FLD на 105 → цель 110.
Кросс FLD цикла N дополнительно ПОДТВЕРЖДАЕТ разворот цикла N/2 (полбара-в-полпериода после экстремума).

### Скальперу
Скальперу на 5-минутках (порядок = приоритет внедрения):

1. ROOFING FILTER — не рисовать, а поставить ПЕРЕД всем: полоса 10..48 баров на 5м = циклы 50 мин..4 ч, ровно скальперский диапазон. Всё остальное считать от filt, не от сырой цены.

2. EVEN BETTER SINEWAVE — главный кандидат: один осциллятор в [-1,+1] без измерения периода, минимум лага. Рисовать линией в подвале с уровнями ±0.85. Чтение: |EBS|>0.85 и держится = ТРЕНДОВЫЙ режим (не контртрендить, входить по откатам в сторону рельса); осциллирует между уровнями = ЦИКЛОВЫЙ режим (фейды от экстремумов). Для 5м Duration=30..40, SSF=8..10.

3. ДОМИНАНТНЫЙ ЦИКЛ — autocorrelation periodogram (не гомодин: устойчивее к шуму, сам Элерс перешёл на него в 2013). Рисовать: число DC (в барах) в углу + опционально heatmap мощности (периоды 10..48 по вертикали, время по горизонтали, яркость=Pwr) — видно, когда цикл вообще есть, а когда спектр размазан (не торговать циклом). DC*5мин = период в минутах.

4. SINEWAVE + LEADSINE — таймер входа в цикловом режиме: кросс LeadSine над Sine = лонг у дна с опережением DC/8 баров (на 24-барном цикле = 3 бара = 15 минут форы). В трендовом режиме (по EBS) — игнорировать полностью.

5. MAMA/FAMA — рисовать обе НА цене. Кросс = смена режима почти без лага; расстояние между ними = сила тренда. FastLimit=0.5, SlowLimit=0.05 штатно работают на 5м. Стоп-ориентир — FAMA.

6. ХЁРСТ НА 5М: номинальные интрадей-циклы ложатся на 5-минутки идеально: 40 мин = 8 баров, 80 мин = 16, 160 мин = 32 — всё внутри полосы 6..50 Элерса. Рисовать: (а) огибающую 16-барного цикла (центрированная SMA-16 ± полуширина) и внешнюю 32-барную — касание внутренней границей внешней = зона разворота; (б) FLD 16-барного цикла = медиана (H+L)/2, сдвинутая на 9 баров вперёд — она уже нарисована в будущее, кросс цены с FLD даёт мгновенную цель target = 2*P_cross − P_extremum (взял полдороги — знаешь вторую половину). Это готовый тейк-профит скальпа.

7. СИНТЕЗ ШКОЛ (главная связка): DC из периодограммы Элерса → подставлять как N в FLD и огибающую Хёрста динамически. Элерс меряет цикл, Хёрст даёт цель хода — одна волна, два инструмента. Для нашего движка это прямая родня аналитическому сигналу Гильберта, который уже стоит на волне: I/Q-конвейер п.1 — тот же математический объект, доминантный цикл и фаза DCPhase — готовые входы для слоя.

### Грабли
1. ГРАДУСЫ vs РАДИАНЫ — источник №1 ошибок порта: весь EasyLanguage Элерса в градусах (ArcTangent, Sine, 360/atan). В numpy: 360/atan_deg(x) == 2π/atan_rad(x); в MAMA кламп DeltaPhase<1 — это 1 ГРАДУС (=π/180 рад), не 1 радиан. Перепутаешь — alpha всегда упрётся в лимит.
2. Все фильтры рекурсивные — прогрев обязателен: ~100 баров (2×48) до доверия числам; первые значения гомодина мусор, P инициализировать 6..15.
3. Считать ТОЛЬКО по закрытым барам — на формирующемся баре всё перерисовывается. FLD не перерисовывается по построению (сдвиг в будущее), центрированная SMA огибающей принципиально не определена на последних N/2 барах — хвост экстраполировать и честно помечать как экстраполяцию (у нас: note, не заглушка).
4. Гомодин при низком SNR и во флэте врёт даже с клампами — Элерс сам ушёл к автокорреляционной периодограмме; гомодин держать как дешёвый (O(1) на бар) вариант, периодограмма O(48²) на бар — на 5м это всё равно копейки.
5. Полоса 6..50 баров жёстко ограничивает видимые циклы: на 5м это 30 мин..~4 ч. Циклы дня/недели этим слоем не видны — не обещать.
6. Spectral dilation: без roofing мощность растёт ~1/f и периодограмма всегда «находит» длинный цикл — препроцессинг не опция, а условие корректности.
7. Уровни ±0.85 (EBS), пороги 0.5 (центроид), Duration 36 vs 40 — эмпирика Элерса, не физика: в нашей рамке это 🟡 язык школы с note о прокси, DC-измерение по формуле — 🔵 механика.
8. Код из книг под копирайтом Wiley — формулы и константы фактами не охраняются, реализовать своим numpy-кодом можно, копировать листинги дословно в публичный репозиторий не стоит.
9. Хёрстовский сдвиг FLD: у самого Хёрста «полпериода», (N/2)+1 — конвенция Sentient Trader; на чётных N разница в 1 бар, зафиксировать одну конвенцию и не смешивать. Цель 2*P_cross−P_extreme «не учитывает поддержки/сопротивления» — предупреждают сами хёрстианцы.
10. По законам школы: финансовые слои — не торговый сигнал, 18+, полюс за человеком (⚫); всё это — измерение волны, не предсказание события. Chapter-номера, кроме подтверждённых (гл. 7 Rocket Science — гомодин, гл. 12 Cycle Analytics — EBS, гл. 1 Cybernetic — Fisher), даны по памяти без веб-подтверждения.

## 3. CWT в реальном времени (Торренс–Компо/Liu)

### Формулы
ОБОЗНАЧЕНИЯ: x[n] — ряд (лог-цена минус среднее окна), n=0..N-1, δt=1 бар (5 мин), ω₀=6, σ² — дисперсия окна.

1) CWT Морле через FFT (T&C ур. 4, 6; совпадает с портом fin_wave_levels._morlet_cwt):
   xh = np.fft.fft(x - x.mean())
   omega = 2*np.pi*np.fft.fftfreq(N, d=dt)
   psi_hat(s) = pi**-0.25 * sqrt(2*pi*s/dt) * np.exp(-0.5*(s*omega - 6.0)**2) * (omega > 0)
   W[j] = np.fft.ifft(xh * np.conj(psi_hat(s_j)))
   Перед FFT дополнить нулями до ближайшей степени двойки (T&C §3g) ИЛИ отражением (см. п.6).

2) Шкалы (ур. 9-10): s_j = s0 * 2**(j*dj), j=0..J; s0 = 2*dt; J = int(log2(N*dt/s0)/dj); для Морле dj <= 0.5 (для гладких полос лучше 0.25).
   Фурье-период (табл. 1): lam = 4*pi/(6 + sqrt(2+36)) = 1.0330; period_j = lam * s_j.
   Обратно: шкала под период P: s = P/1.0330.

3) Выпрямление Liu–Liang–Weisberg 2007: E[j,n] = |W[j,n]|**2 / s_j.
   Зачем: обычный |W|² при равных амплитудах синусов даёт пики, растущие со шкалой (медленные систематически «громче»); физически согласованная энергия = коэффициент² / шкала — пики сравнимы между шкалами. Замечание: T&C ур. 14 и 24 уже несут 1/s внутри сумм — выпрямление согласовано с сохранением дисперсии.

4) Конус влияния (T&C табл. 1, §3g). e-folding время τ_s = sqrt(2)*s. КАНОН: на удалении d (в времени) от края доверяем периодам P <= (lam/sqrt(2))*d = 0.7305*d, т.е.
   d_edge = np.minimum(np.arange(N), np.arange(N)[::-1]) * dt
   coi_period = (lam/np.sqrt(2)) * d_edge          # T&C reference code: coi = fourier_factor/sqrt(2)*dt*d
   trust = period[:,None] <= coi_period[None,:]
   ВНИМАНИЕ: в родительском порте (fin_wave_levels.py:125) стоит coi_period = sqrt(2)*d*lam — это в 2 раза МЯГЧЕ канона (доверяет P<=1.46d вместо P<=0.73d). Для живого правого края брать канон.

5) Честная поправка среднего внутри COI при нулевом паддинге (T&C §4c, точная цитата): «mean spectrum is reduced by a factor of (1 - ½ e^{-2t/τs})», t — расстояние до края. Несмещённая оценка ожидания:
   E_corr[j,n] = E[j,n] / (1.0 - 0.5*np.exp(-2.0*d_edge[n]/(np.sqrt(2)*s_j)))
   На самом краю (t=0) множитель = 2. Дисперсия при этом раздута — значимость у края всё равно слабее, честность = показывать как «предварительно».

6) Правила честного правого края (все четыре практики, по убыванию честности):
   a) СДВИГ НАЗАД: последний доверенный столбец шкалы s лежит на sqrt(2)*s от края; рисовать «сейчас» полосы на t_now - sqrt(2)*s_band, правее — штрихованная зона «предварительно».
   b) Нулевой паддинг + поправка п.5 — несмещённое среднее, шумно.
   c) Зеркальное дополнение: xp = np.concatenate([x, x[::-1]]) (или анти-зеркало, сохраняющее наклон: 2*x[-1]-x[-2::-1]); убирает разрыв, неявно предполагает «будущее ≈ зеркало прошлого»; лучший вариант — паддинг AR-прогнозом (forecast padding, bioRxiv 2025). COI концептуально остаётся!
   d) Односторонний (каузальный) вейвлет для стрима — банк комплексных резонаторов с известной групповой задержкой ~s:
      a_k = np.exp((1j*w_k - 1.0/s_k)*dt);  y_k[n] = g_k*x[n] + a_k*y_k[n-1]
      (каскад 4 штук ≈ гауссова огибающая; теория: Lindeberg, time-causal wavelets, arXiv:2510.05834). Энергия запаздывает, но никогда не фантазирует.

7) Красный шум AR(1) (T&C ур. 15-16): x_n = α x_{n-1} + z_n;
   P_k = (1 - α**2) / (1 + α**2 - 2*α*np.cos(2*np.pi*dt/lam_j))   # lam_j = период шкалы j
   Оценка α (T&C §4a): α = (a1 + np.sqrt(max(a2, 0)))/2, где a1, a2 — автокорреляции лагов 1 и 2; fallback α = max(a1, 0) при a2<0.

8) Точечная значимость (ур. 18): |W_n(s)|²/σ² распределено как (1/2)·P_j·χ²₂. 95%: χ²₂(0.95)=5.991:
   signif = 0.5 * 5.991 * P_j * σ²        # порог для НЕвыпрямленного |W|²; для E=|W|²/s делить порог на s_j.

9) Энергия полосы = усреднение по шкалам (ур. 24-28, Морле-константы табл. 2: Cδ=0.776, γ=2.32, δj0=0.60, ψ0(0)=π^{-1/4}):
   Wband[n] = (dj*dt/0.776) * np.sum(np.abs(W[j1:j2+1, n])**2 / s[j1:j2+1, None], axis=0)   # ур. 24, 1/s уже внутри
   Savg = 1.0/np.sum(1.0/s[j1:j2+1]);  Smid = s0 * 2**(0.5*(j1+j2)*dj);  na = j2-j1+1
   Pbar = Savg * np.sum(P[j1:j2+1]/s[j1:j2+1])                                              # ур. 27
   nu = (2.0*na*Savg/Smid) * np.sqrt(1.0 + (na*dj/0.60)**2)                                 # ур. 28
   W95 = (dj*dt*σ²/(0.776*Savg)) * Pbar * chi2_ppf(0.95, nu)/nu                             # ур. 26
   Без scipy — Wilson–Hilferty: chi2_ppf(0.95,nu) ≈ nu*(1 - 2/(9*nu) + 1.6449*np.sqrt(2/(9*nu)))**3.
   Усреднение по времени, если надо (ур. 23): nu_t = 2*np.sqrt(1 + (na_t*dt/(2.32*s))**2); внутри COI na уменьшать примерно на половину числа точек в конусе (T&C §5a).

10) Индекс «бьёт ключом vs энергии нет» — нормировка к скользящему фону:
   b[n] = np.log(Wband[n] + 1e-12); фон = хвостовое окно K баров БЕЗ последних ceil(sqrt(2)*s_mid_полосы) предварительных столбцов;
   z[n] = (b[n] - np.median(bg)) / (1.4826*np.median(np.abs(bg - np.median(bg))) + 1e-12)   # robust z по MAD
   q[n] = np.mean(bg < b[n])                                                                # квантильный ранг
   Критерии: E+ «энергия питает ход»: Wband > W95 (значимо против красного шума) И q>=0.8 И наклон Wband по последним доверенным столбцам > 0.
   E− «энергии нет — откат/дрейф»: Wband < σ²·ожидание фона (z<0) ИЛИ q<=0.2 при падающем наклоне → ход на инерции, подпитки нет.
   Между ними — E0 «фон».

11) Стрим на 5-минутках. Шкалы под полосы: fast 15м→s=2.90 бар; mid 2ч→s=23.2 бар; slow 8ч→s=92.9 бар. Носитель Морле |ψ| < e^{-8} за |t|>4s ⇒ новый бар меняет только хвост длиной ~4·s_max ≈ 372 столбца. Практика: полный FFT-пересчёт окна N=1024 бар (~19 шкал при dj=0.5) — единицы миллисекунд в numpy, делать каждый бар; инкрементально (на тиках) считать только последний столбец прямой свёрткой:
   eta = np.arange(-L, 1)*dt/s;  L = int(4*s/dt)
   psi = np.pi**-0.25 * np.exp(1j*6.0*eta - 0.5*eta**2)
   W_last = np.sqrt(dt/s) * np.dot(x[-L-1:], np.conj(psi[::-1]))
   Сколько баров надо: чтобы slow-полоса 8ч имела хоть один столбец вне COI — N > 2*sqrt(2)*92.9 ≈ 263 бара; для фоновой статистики (>=5 независимых периодов slow) — N >= 131+5*96 ≈ 611; рекомендация N=1024 бара (~3.5 суток 24/7), степень двойки.

КАК РИСОВАТЬ: (1) тепловая карта период×время (лог-ось периодов 10 мин — 16 ч), выпрямленная мощность 0..99, вне канонического COI (P>0.73·d) — затемнение, как в _spectro_block; (2) под ней три ленты полос, каждая крашена состоянием: E+ ярко («энергия бьёт ключом — ход питается»), E0 нейтрально, E− погашено («энергии нет — ход на инерции, вероятен откат»); тонкая линия — 95%-порог красного шума (ур. 26-28); (3) правый край: последняя ДОВЕРЕННАЯ точка каждой ленты рисуется со сдвигом назад на √2·s полосы, правее — штрихованная зона «предварительно» со значениями от зеркального (или AR-прогнозного) паддинга при пониженной непрозрачности — глаз видит и честную оценку, и живой хвост, и не путает их.

ЧТЕНИЕ ДЛЯ СКАЛЬПА (язык школы 🟡, полюс за человеком ⚫): fast E+ при mid E+ — движение с подпиткой на двух глубинах, ход «дышит»; fast E+ при mid E− — всплеск без опоры, короткая вспышка; fast E− после хода при цене у экстремума — импульс исчерпан, откат/боковик вероятнее продолжения; slow E+ — день структурный, качели глубокие; всё сопровождать note «🔵 механика: CWT Морле ω₀=6, T&C 1998 + Liu 2007; ⚫ не торговый сигнал, 18+».

### Грабли
1) НАЙДЕНО РАСХОЖДЕНИЕ В РОДИТЕЛЬСКОМ ПОРТЕ: fin_wave_levels.py:125 считает coi_period = √2·d·λ, а канон T&C (reference-код) — coi = (λ/√2)·d. Порт доверяет краю в 2 раза шире канона. Для дневного движка это лишь мягкость затемнения, но для живого 5-минутного правого края обязателен канон 0.73·d — иначе «энергия сейчас» будет систематически фантазией края. Достойно записи в бэклог NEXT_CHAT (раздел 0.2), править должен родитель, не этот отчёт. 2) Ур. 28 (DOF полосы) валидно только до 95% доверия — выше 95% распределение уходит от χ² (T&C прямо предупреждают). 3) χ²-значимость предполагает гауссов стационарный ряд; 5-минутные приращения цены тяжелохвосты и с кластеризацией волатильности — AR(1)-фон занижен в спокойные часы и завышен в бурные. Красношумный порог держать как «механический» 🔵, но рабочий критерий E+/E− строить на робастном z/квантиле по MAD (формула 10) — и честно пометить в note, что фон эмпирический (🟡 прокси). 4) Выпрямление Liu меняет единицы: пороги ур. 18 выведены для НЕвыпрямленного |W|²/σ² — при работе в E=|W|²/s делить пороги на s_j, иначе значимость перекошена по шкалам. 5) Зеркальный/прогнозный паддинг НЕ создаёт информацию — COI остаётся; паддинг лишь убирает артефакт разрыва. Правый край всегда либо «сдвинут назад», либо «предварительно» — третьего честного варианта нет. 6) Поправка (1-½e^{-2t/τs}) чинит только ожидание, не дисперсию — у края оценка несмещённая, но шумная. 7) Вход — лог-цена, демин по окну; на приращениях спектр умножается на |1-e^{-iωδt}|² и полосы перекашиваются к быстрым — выбор входа зафиксировать и назвать в note. 8) Не-24/7 инструменты: гэпы сессий рвут AR(1) и COI — считать по непрерывным сегментам, не сшивать через ночь молча. 9) α=(a1+√a2)/2 ломается при a2<0 — нужен fallback max(a1,0), иначе NaN в пороге. 10) Нет данных для фона (окно короче 263 бар для slow) — по закону школы NO DUMMIES: полоса отдаёт None и честный note, не «примерно». 11) Законы школы: слой — рядом новым модулем, ядро не трогать, try/except, константы из kernel.py, ⚫ «не торговый сигнал, 18+» в каждом note. 12) Честное раскрытие исследования: полностью прочитан только Torrence&Compo 1998; Liu 2007 и работы по краю — на уровне аннотаций/резюме; формула Liu (деление на шкалу) подтверждена независимо аннотацией журнала и авторским PDF-заголовком, но постраничная сверка Liu не проводилась.
