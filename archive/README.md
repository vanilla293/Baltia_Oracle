# archive/ — то, что было ДО v5 (не удалять, не править)

- `pythia_4.5.4_zerotouch.zip` — исходный архив ПИФИИ 4.5.4 «zero-touch», который
  владелец передал агенту 18.09.2026 как отправную точку v5. Внутри: весь бэкенд
  4.5.4 (`backend/`, включая `lab/`), старый тёмный фронт (`frontend/index.html`,
  261 КБ), документы (`NEXT_CHAT.md`, `README.md`, `CLAUDE.md` эпохи REAL SKY,
  `docs_*`), `data/` со служебными файлами, `start.bat`/`start.sh`, `selfcheck.py`,
  `build_release.sh`. Распаковывать только для сверки: рабочий код живёт в корне.
- `docs_4.5/` — документы эпохи 4.x, вынесенные из корня, чтобы не путать с v5:
  `docs_ЗАПУСК.txt` (запуск 3.17 «Хищник»), `docs_ЗАПУСК_ИИ_ПИЛОТ.txt` (запуск
  ИИ-пилота 4.5.2), `docs_ЗАЩИТА_ПРОЕКТА.md` (перебор комбинаций для защиты),
  `BACKTEST_PROTOCOL.md` (протокол бэктестов для лаборатории), `docs_AETHER_ROADMAP.md`
  (дорожная карта эфирного слоя), `docs_FORMULY_EFIRA_v3_0_0.html` (формулы эфира),
  `docs_KAK_USTROENO_v3.html` (как устроена 3.x).
- `selfcheck_4.5.py` — старый скрипт самопроверки 4.5 (модули той эпохи).
- `build_release_4.5.sh` — старый сборщик релизного zip.

Что ещё осталось от 4.5 в рабочем коде: `backend/*.py` старой эпохи используются v5
как библиотека (см. `docs/СТРУКТУРА_ПРОЕКТА.md`), `backend/lab/` — исследовательские
стенды, `NEXT_CHAT.md` — журнал всех эпох (v5 сверху).
