# Baltia Oracle

Личный ИИ-помощник в Telegram на DeepSeek. Говоришь голосом, а он ставит напоминания, ведёт календарь, помнит дни рождения, разбирает идеи и новости. И спорит, когда считает, что ты неправ.

Это не услужливый чат-бот, а напарник с памятью и собственным мнением. Он живёт на твоём компьютере или сервере, слушается только тебя, а данные хранит у тебя же.

## Что он умеет

- ⏰ **Напоминания и будильник.** Например: «напомни завтра в 10 позвонить маме» или «каждый будний день в 9:30 — планёрка». Важные напоминания («и не отставай, пока не сделаю») приходят каждые 3 минуты и всё настойчивее, пока не нажмёшь «Готово». Будильник выключается только решённым примером, так что полусонным его не смахнёшь.
- 📅 **Календарь.** Встречи, поездки и повторяющиеся события с напоминанием заранее (по умолчанию за 30 минут). Календарь выгружается файлом `.ics`: открываешь его, и события появляются в Google, Apple или Outlook.
- 🎂 **Дни рождения.** Бот предупредит заранее, а в сам день пришлёт поздравление, которое не стыдно отправить: без «счастья, здоровья, успехов», под конкретного человека. Не понравилось — жми «🔁 Другой вариант».
- 💡 **Идеи.** Идея получает честную оценку от 1 до 10 (большинство идей — это 4–6, и это нормально): что в ней сильное, что её убьёт, какой первый шаг. По просьбе «додумай глубоко» думающая модель в фоне разберёт рынок, риски и способ проверить идею за 1–2 недели, а итог придёт отдельным сообщением. «Найди мою идею про кофейню» тоже сработает: поиск учитывает окончания слов, а если прямого совпадения нет, бот просматривает свежие идеи и выбирает подходящую по смыслу.
- 📋 **Проекты и задачи.** Сроки, приоритеты, напоминания к сроку. Бот видит, какой проект стоит без движения.
- 📰 **Новости.** Ленты из разных лагерей: российские госСМИ, независимые и зарубежные издания. В разборе отделено, что факт (кто подтверждает), что заявление (кто сказал и зачем), а что интерпретация. Видно, как одно и то же подают разные стороны и о чём они молчат. Дайджест приходит каждое утро, а по команде `/news` — в любой момент.
- 🔎 **Интернет и погода.** Бот ищет в сети (DuckDuckGo) и читает ссылки, которые ты присылаешь. Погоду берёт с Open-Meteo. Ключи для этого не нужны.
- 🧠 **Память.** Запоминает важное о тебе (людей, планы, привычки, работу) и пользуется этим. Посмотреть можно командой `/memory`, убрать лишнее — командой `/forget`.
- 🗣 **Своё мнение и дневник.** Бот записывает свои позиции и меняет их только под аргумент. Ночью он перечитывает день и пишет дневник: где ты буксуешь и о чём спросить завтра.
- 🔔 **Инициатива.** Бот сам ставит себе задачу вернуться к теме и пишет первым: «Ты собирался позвонить юристу — позвонил?». По утрам присылает сводку на день.
- 🎙 **Голос.** Понимает голосовые сообщения, а на голосовое отвечает голосом.
- 💬 **Твои чаты (по желанию).** Бот читает твой Telegram, показывает, кто ждёт ответа, и пишет черновик ответа в твоём стиле. Отправляется черновик только по твоей кнопке.

### Чем он отличается от Пифии

В Пифии каждый вопрос был отдельным чатом с максимальным размышлением: ответ мог идти до 30 минут, и следующий вопрос начинался с чистого листа. Оракул устроен наоборот:

- **Живой диалог.** Он помнит, о чём вы говорили: свежие реплики держит целиком, а старые сворачивает в конспект.
- **Память и позиции.** Он знает тебя и сохраняет собственное мнение от разговора к разговору.
- **По умолчанию он быстрый.** Отвечает за секунды. Глубокое размышление включается по запросу (`/deep`, `/mode`) или идёт в фоне, когда ты не ждёшь ответа.

## Быстрый старт

**Что понадобится:**
- компьютер или сервер, который включён, пока нужен бот (бот работает, пока запущен);
- Python 3.10 или новее ([python.org](https://www.python.org/downloads/)) или Docker;
- минут 10–15.

### 1. Создай бота в Telegram

1. Открой [@BotFather](https://t.me/BotFather) и отправь `/newbot`.
2. Имя может быть любым («Оракул»). Username пишется латиницей и должен заканчиваться на `bot`, например `my_oracle_bot`.
3. BotFather пришлёт токен вида `1234567890:AAE…`. Это **BOT_TOKEN**, никому его не показывай.

### 2. Возьми ключ DeepSeek

1. Зарегистрируйся на [platform.deepseek.com](https://platform.deepseek.com).
2. Пополни баланс (Top up). API платный, но дешёвый. С пустым счётом бот будет отвечать ошибкой 402.
3. В разделе **API keys** нажми **Create new API key** и скопируй ключ `sk-…`. Это **DEEPSEEK_API_KEY**. Ключ показывают один раз.

Модели:
- `deepseek-flash` — модель по умолчанию. Быстрая, подходит для всего.
- `deepseek-v4-pro` — по желанию, для глубокого режима: `LLM_MODEL_DEEP=deepseek-v4-pro`. Она сильнее, но медленнее и обычно дороже. Работает только в глубоком режиме: `/deep`, `/mode`, разбор идей, ночная рефлексия.

### 3. Голос

**Вариант А: Groq (проще).** Зайди на [console.groq.com](https://console.groq.com), открой **API Keys**, нажми **Create API Key** и скопируй ключ `gsk_…`. Это **GROQ_API_KEY**. Сервис бесплатный в пределах лимитов, голосовое распознаётся за секунду-две.

**Вариант Б: локально.** Распознавание через faster-whisper на твоём компьютере. Запись никуда не уходит, но это медленнее: на обычном процессоре — несколько секунд на короткое голосовое. Модель скачивается один раз (для `small`, которая стоит по умолчанию, — около полугигабайта). Впиши в `.env`:
```
STT_PROVIDER=local
```
`start.sh` и `start.bat`, увидев эту строку, сами поставят faster-whisper. Вручную это делается так: `.venv/bin/pip install -r requirements-voice.txt` (в Windows — `.venv\Scripts\pip install -r requirements-voice.txt`). В Docker поставь `LOCAL_WHISPER: "1"` в `docker-compose.yml` и выполни `docker compose up -d --build`.

Без голоса бот тоже работает: просто пиши ему текстом.

### 4. Заполни настройки

Скопируй образец:
```bash
cp .env.example .env          # Linux / macOS
copy .env.example .env        # Windows (или просто запусти start.bat — он сделает это сам)
```

Открой `.env` в любом текстовом редакторе и впиши своё:
```
BOT_TOKEN=1234567890:AAE...
DEEPSEEK_API_KEY=sk-...
GROQ_API_KEY=gsk_...
OWNER_NAME=Саша
TIMEZONE=Europe/Kaliningrad
WEATHER_CITY=Калининград
```
Остальное можно не трогать: в `.env.example` каждая строка подписана. Комментарии пиши **только отдельной строкой**, потому что `KEY=значение # коммент` испортит значение.

### 5. Запусти

**Linux / macOS:**
```bash
./start.sh
```
При первом запуске скрипт создаст окружение `.venv` и поставит зависимости (минута-две), потом запустит бота. Остановить бота — `Ctrl+C`.

**Windows:** дважды щёлкни по `start.bat`. Окно не закрывай: пока оно открыто, бот работает.

**Docker:**
```bash
docker compose up -d          # собрать и запустить в фоне
docker compose logs -f        # смотреть лог
```

### 6. Скажи боту, что ты хозяин

1. Напиши своему боту `/start`. Он ответит: «Твой Telegram id: 123456789».
2. Впиши этот id в `.env`: `OWNER_ID=123456789`.
3. Перезапусти бота:
   - Linux / macOS: `Ctrl+C`, потом снова `./start.sh`;
   - Windows: закрой окно и снова запусти `start.bat`;
   - Docker: `docker compose up -d --force-recreate`.

Готово. Теперь бот слушается только тебя, а чужим отвечает «Это личный бот.».

## Как с ним говорить

Говорить можно голосом или текстом, как с человеком. Команды знать не обязательно.

| Говоришь | Что он сделает |
|---|---|
| «Разбуди меня завтра в семь, и чтобы точно встал» | Поставит будильник, который звонит, пока не решишь пример |
| «Каждый будний день в 9:30 напоминай про планёрку» | Поставит повторяющееся напоминание |
| «Напомни в 18:00 забрать посылку и не отставай, пока не заберу» | Поставит напоминание, которое повторяется до «Готово» |
| «В пятницу в три стоматолог, напомни за час» | Добавит событие в календарь с напоминанием за час |
| «У Маши день рождения 14 марта, ей будет 30, она моя сестра» | Запомнит, предупредит заранее и в сам день пришлёт поздравление |
| «Слушай, идея: кофейня-автомат у вокзала. Как тебе?» | Честно разберёт с оценкой и сохранит идею |
| «Додумай её глубоко» | Разберёт идею в фоне, итог пришлёт через несколько минут |
| «Найди мою идею про кофейню» | Найдёт идею и покажет с оценкой |
| «Заведи проект „Ремонт“, первая задача — вызвать замерщика до пятницы» | Заведёт проект и задачу со сроком и напоминанием |
| «Что там с новостями про Калининград?» | Соберёт свежие новости и разберёт их: факт / заявление / интерпретация |
| «Какая погода на выходных?» | Покажет прогноз |
| «Запомни: я не пью кофе после шести» | Запишет это в память |
| «Что ты думаешь про мой план уйти с работы?» | Скажет своё мнение с аргументами, без поддакивания |
| «Выгрузи календарь» | Пришлёт файл `.ics` |
| «Кто мне писал? Ответь Серёже, что буду в семь» | С userbot покажет непрочитанные и черновик с кнопкой «Отправить» |

## Почему он быстрый

DeepSeek V4 по умолчанию «размышляет» перед каждым ответом, и даже на «привет» уходят десятки секунд, а то и минуты. Оракул делит работу на три режима:

- **Быстрый (по умолчанию).** `deepseek-flash` с выключенным размышлением отвечает за секунды. Этого хватает почти на всё: разговор, напоминания, календарь, поиск, новости.
- **Глубокий, когда нужно.** `/deep вопрос` — один вопрос с размышлением. `/mode` включает глубокий режим для всех сообщений, и той же командой он выключается. Модель задаёт `LLM_MODEL_DEEP`, глубину — `LLM_DEEP_EFFORT`. Ответ может идти минуты, но это ты выбрал сам.
- **Фоновый, чтобы не ждать.** Тяжёлое обдумывается без тебя. «Додумать идею» идёт в фоне, и итог приходит отдельным сообщением. Ночная рефлексия запускается в 03:30, пока ты спишь.

Если хочется чуть больше аккуратности в обычном разговоре, поставь `LLM_FAST_THINKING=low`: ответы станут немного медленнее.

## Почему он не поддакивает

Честно: это языковая модель, а не человек. Такие модели склонны соглашаться с собеседником, так их учили. Одной фразы «будь честным» в промпте мало: под напором модель всё равно сдаётся.

Поэтому характер Оракула держится не на промпте, а на состоянии, которое он копит сам:

- **Позиции (`/opinions`).** Когда бот формулирует мнение о чём-то важном, он записывает тему, позицию, доводы и уверенность в процентах. Эти позиции каждый раз лежат у него перед глазами. Изменить позицию можно только с объяснением, что именно переубедило, и прежняя версия остаётся в истории. «Ты повторяешь, но аргумента не добавил» для него нормальный ответ.
- **Дневник (`/journal`).** Каждую ночь бот перечитывает день и пишет себе заметку: что заметил, где ты буксуешь, на что завтра надавить. Утром эта заметка у него в контексте.
- **Память о тебе (`/memory`).** Люди, планы, привычки, работа. Бот опирается на то, что знает, и не угадывает заново.
- **Своя повестка.** Бот сам ставит себе задачи вернуться к теме и возвращается к тому, что ты отложил.

Промпт задаёт только правила игры: не льстить, отвечать определённо, отличать напор от аргумента, а в твоих личных делах оставлять последнее слово за тобой. Содержание мнений — то, до чего бот дошёл сам.

Гарантии это не даёт: модель может ошибаться и иногда уступать. Заметил, что он поддакивает, — скажи ему прямо.

## Совсем свободная модель

У API DeepSeek свои ограничения: на некоторые темы (например, часть политических, особенно про Китай) он отвечает уклончиво или отказывается. Промпт тут не поможет, потому что это фильтр на стороне сервиса.

Выход — подключить другого провайдера. Подойдёт любой **OpenAI-совместимый API с поддержкой вызова инструментов** (function calling / tools). Без этой поддержки бот не сможет ставить напоминания, вести календарь и остальное.

**OpenRouter.** Сотни моделей по одному ключу ([openrouter.ai](https://openrouter.ai) → Keys):
```
DEEPSEEK_API_KEY=
LLM_BASE_URL=https://openrouter.ai/api/v1
LLM_API_KEY=sk-or-...
LLM_MODEL=<модель с поддержкой tools из каталога OpenRouter>
LLM_MODEL_DEEP=<модель посильнее — по желанию>
```
Если в `LLM_BASE_URL` не DeepSeek, бот берёт `LLM_API_KEY`, а `DEEPSEEK_API_KEY` — только когда `LLM_API_KEY` пуст. Надёжнее всё же стереть `DEEPSEEK_API_KEY`, чтобы ключ DeepSeek не ушёл чужому сервису.

**Ollama.** Модель работает на твоём компьютере, и ничего не уходит наружу:
```
DEEPSEEK_API_KEY=
LLM_BASE_URL=http://localhost:11434/v1
LLM_API_KEY=ollama
LLM_MODEL=qwen3:14b
```
`qwen3:14b` здесь только пример. Ключ Ollama не нужен, но поле не должно быть пустым. Модель выбирай с меткой **tools** на [ollama.com/search](https://ollama.com/search). Если бот запущен в Docker, пиши вместо `localhost` адрес `host.docker.internal`.

**LM Studio.** Включи сервер (Developer → Start Server) и впиши адрес `http://localhost:1234/v1`, `LLM_API_KEY=lmstudio`. В `LLM_MODEL` укажи имя загруженной модели.

Что учесть:
- Особые параметры DeepSeek (выключение размышления, `reasoning_effort`) отправляются, только если в адресе API или в имени модели есть «deepseek». Остальным провайдерам уходит обычный запрос.
- У других провайдеров глубокий режим — это просто другая модель (`LLM_MODEL_DEEP`). Поставь туда модель посильнее или «думающую».
- Локальные модели не проходят через чужие серверные фильтры, но на обычном компьютере они заметно слабее и медленнее DeepSeek. Чем меньше модель, тем чаще она путается в инструментах.
- Степень свободы зависит от модели: у многих открытых моделей есть свои встроенные отказы.

## Чтение своих чатов (userbot)

Это необязательная функция. Бот подключается к **твоему** аккаунту Telegram (не к боту) и может:
- показать, кто написал и что осталось непрочитанным (`/chats`, «кто мне писал?»);
- прочитать переписку («что там Серёжа писал?»);
- написать черновик ответа в твоей манере (он смотрит, как ты обычно пишешь) и прислать его с кнопками **Отправить / Переписать / Не надо**;
- при `USERBOT_NOTIFY=1` сообщать о новых личных сообщениях с кнопкой «Предложить ответ».

**Сам бот ничего не отправляет.** У модели просто нет инструмента «отправить». Сообщение уходит только после нажатия твоей кнопки «Отправить» под черновиком.

### Как включить

1. Зайди на [my.telegram.org](https://my.telegram.org) своим номером и открой **API development tools**. Создай приложение (название и описание любые) и скопируй **App api_id** и **App api_hash**.
2. Впиши в `.env`:
   ```
   USERBOT_ENABLED=1
   TG_API_ID=1234567
   TG_API_HASH=0123456789abcdef0123456789abcdef
   USERBOT_NOTIFY=1
   ```
3. Один раз войди в аккаунт из терминала. Скрипт спросит телефон, код из Telegram и пароль двухэтапной проверки, если он есть:
   ```bash
   .venv/bin/python -m oracle.userbot_login                          # Linux / macOS
   .venv\Scripts\python -m oracle.userbot_login                      # Windows
   docker compose run --rm oracle python -m oracle.userbot_login     # Docker
   ```
4. Перезапусти бота и напиши `/chats`.

### Безопасность — прочитай

- **Файл `data/userbot.session` — это полный доступ к твоему аккаунту.** С ним можно читать и писать от твоего имени без кода и пароля. Никому его не отдавай, никуда не выкладывай и не клади в git (`.gitignore` его уже исключает).
- Если файл утёк или бот больше не нужен, открой Telegram → Настройки → Устройства и заверши сеанс «Baltia Oracle».
- Когда ты просишь прочитать чат или написать черновик, текст переписки уходит модели (DeepSeek или твоему провайдеру). Это касается и сообщений других людей, учитывай это.
- Автоматизация личных аккаунтов — серая зона правил Telegram. Бот только читает и отправляет по твоей кнопке, но риск ограничений аккаунта остаётся на тебе.

## Где хранятся данные и приватность

Всё хранится у тебя, в папке `data/`:
- `oracle.db` — одна база SQLite: диалог, память, позиции, дневник, напоминания, календарь, дни рождения, идеи, проекты;
- `userbot.session` — вход в твой аккаунт, если включал userbot;
- `whisper/` — модель локального распознавания, если выбран `local`.

Ключи лежат в `.env`. Не выкладывай `data/` и `.env` никуда, `.gitignore` их уже исключает.

**Что уходит наружу и куда:**

| Куда | Что | Когда |
|---|---|---|
| Telegram | Твои сообщения боту и его ответы | Всегда, это мессенджер |
| DeepSeek (или твой `LLM_BASE_URL`) | Характер бота, факты о тебе, его позиции, дневник, конспект и последние реплики разговора, результаты инструментов (новости, найденные страницы, по твоей просьбе — переписка из чатов) | На каждое сообщение и в фоновых задачах |
| Groq или OpenAI | Запись голосового | Только если выбран этот провайдер. С `local` не уходит ничего |
| Microsoft (edge-tts) | Текст ответа для озвучки | Только когда бот отвечает голосом. При `TTS_DEFAULT=off` — никогда |
| DuckDuckGo и сайты | Поисковые запросы, адреса страниц | Когда бот ищет или читает ссылку |
| Open-Meteo | Город или координаты | При запросе погоды |
| RSS-ленты новостей | Ничего о тебе, просто скачивание | При обновлении новостей |

Больше никуда: ни аналитики, ни телеметрии. DeepSeek — китайская компания, и как она хранит запросы, написано в её политике конфиденциальности. Если нужно, чтобы разговоры не покидали дом, подключи локальную модель ([см. выше](#совсем-свободная-модель)) и `STT_PROVIDER=local`.

**Резервная копия.** Команда `/backup` присылает файл базы прямо в чат. Можно и вручную: останови бота и скопируй папку `data/`. Чтобы восстановить, останови бота, положи `oracle.db` обратно в `data/` и запусти.

## Настройка расписания

Время указывается местное, в часовом поясе `TIMEZONE`. `off` выключает задачу.

| Настройка | По умолчанию | Что происходит |
|---|---|---|
| `MORNING_BRIEF_TIME` | `08:00` | Утренняя сводка: события, напоминания, дни рождения, задачи, погода и одно дело, на которое стоит надавить |
| `NEWS_DIGEST_TIME` | `09:00` | Дайджест новостей |
| `BIRTHDAY_TIME` | `09:00` | Дни рождения: предупреждение заранее и поздравление в сам день |
| `REFLECTION_TIME` | `03:30` | Ночная рефлексия: дневник, пересмотр позиций, что вспомнить завтра |
| `TIMEZONE` | `Europe/Moscow` | Часовой пояс, например `Europe/Kaliningrad`, `Asia/Yekaterinburg`, `Europe/Minsk` |

Если в нужное время бот был выключен, но включился не позже чем через 3 часа, задача выполнится сразу после включения. Позже она просто пропускается до завтра.

Напоминания:
- `NAG_INTERVAL_MIN=3` — раз в сколько минут повторять неотмеченное;
- `NAG_MAX=20` — сколько раз повторить, прежде чем сдаться;
- `WAKE_CHALLENGE=1` — будильник снимается только решённым примером (`0` — обычной кнопкой).

## Чтобы работал круглосуточно

Бот отвечает, только пока запущен. Если ноутбук уснул, будильник не сработает. Для надёжности запусти бота на сервере (подойдёт недорогой VPS или домашний мини-ПК):

- **Docker:** `docker compose up -d`. Бот сам поднимется после перезагрузки и падений (`restart: unless-stopped`).
- **systemd (Linux без Docker):** готовый файл службы с инструкцией лежит в [`docs/oracle.service`](docs/oracle.service).

**Обновление:** выполни `git pull`, потом перезапусти бота так же, как запускал. `start.sh` и `start.bat` сами доставят зависимости, если поменялся `requirements.txt`. В Docker нужно `docker compose up -d --build`, для службы — `sudo systemctl restart baltia-oracle`.

## Если что-то не так

**«ключ LLM не принят (401)»**
Ключ в `DEEPSEEK_API_KEY` с ошибкой: лишний пробел, обрезан или удалён на сайте. Создай новый ключ и впиши заново.

**«на счёте DeepSeek кончились деньги (402)»**
Пополни баланс на [platform.deepseek.com](https://platform.deepseek.com).

**«модель не принята API»**
В `LLM_MODEL` или `LLM_MODEL_DEEP` опечатка, или модель сняли с API. Если сломалась глубокая модель, бот сам откатится на быструю.

**Бот молчит.** Проверь по порядку:
1. Бот запущен? Окно `start.bat` или терминал открыт; в Docker проверь командой `docker compose ps`.
2. `OWNER_ID` — это твой id, числом и без кавычек. Узнать его можно командой `/start`.
3. После правки `.env` бот перезапущен? В Docker нужен `docker compose up -d --force-recreate`, простой `restart` новые настройки не подхватит.
4. Не запущена ли вторая копия с тем же токеном? В логе это выглядит как `Conflict: terminated by other getUpdates request`. Останови лишнюю копию.

**Не понимает голосовые / «голос не настроен».**
Нет `GROQ_API_KEY` и не стоит faster-whisper. Команда `/status` покажет, какой способ распознавания выбран и почему он выключен.

**Время напоминаний сдвинуто на несколько часов.**
Неверный `TIMEZONE`. Исправь его, перезапусти бота и пересоздай напоминания, поставленные до исправления.

**Отвечает долго.**
Проверь, не включён ли глубокий режим: `/mode` вернёт быстрый. В `.env` должно быть `LLM_FAST_THINKING=off`. Разбор идей и `/deep` долгие по задумке.

**Нет погоды в сводке.**
Впиши `WEATHER_CITY` (или `WEATHER_LAT` и `WEATHER_LON`).

**Windows:**
- «Не нашёл Python»: поставь Python с [python.org](https://www.python.org/downloads/) и в установщике отметь галочку **Add python.exe to PATH**.
- Вместо русских букв кракозябры: запусти через Windows Terminal (он есть в Windows 11) или поставь окну шрифт Consolas.
- Бот работает, пока открыто окно и компьютер не спит. Для круглосуточной работы нужен сервер или Docker.
- `.env` правь Блокнотом и не добавляй расширение `.txt` при сохранении: файл должен называться ровно `.env`.

**Linux:** если `python3 -m venv` падает, поставь пакет: `sudo apt install python3-venv`.

**Docker:** ошибка `env file .env not found` значит, что сначала нужно создать `.env` (шаг 4 быстрого старта).

**Нужны подробности:** поставь `LOG_LEVEL=DEBUG`, перезапусти бота и смотри лог.

## Для разработчиков

Архитектура, контракты модулей и формат кнопок описаны в [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md).

```
oracle/
  config.py      настройки из .env (все переменные — в .env.example)
  llm.py         клиент DeepSeek / OpenAI-совместимого API: быстрый и глубокий режимы
  agent.py       мозг: системный промпт, цикл инструментов, конспекты, ночная рефлексия
  persona.py     характер и сборка системного промпта
  db.py          SQLite (aiosqlite) + поиск по-русски (FTS5 с грубым стеммером)
  timeutil.py    время, часовые пояса, повторы (RRULE)
  tools/         инструменты модели: reminders, calendar, birthdays, ideas, projects, memory, news, tg_chats
  services/      scheduler, brief, news, stt, tts, userbot
  bot/           Telegram (aiogram 3): команды, кнопки, отрисовка
  userbot_login.py   вход userbot в аккаунт
tests/           pytest, без сети
```

**Тесты:**
```bash
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements-dev.txt
python -m pytest -q
```
Тесты не ходят в сеть и не требуют ключей: модель, Telegram, сеть и часы подменены (фикстуры в `tests/conftest.py`).

**Новый инструмент:** напиши функцию `async def h(ctx, *, ...) -> dict` с декоратором `@tool(...)` в модуле из `oracle/tools/`. Если модуль новый, добавь его в `MODULES` в `oracle/tools/__init__.py`. Описание инструмента пиши по-русски и с точным форматом аргументов: его читает модель.

**Файлы запуска:** `start.sh` / `start.bat` (локально), `Dockerfile` + `docker-compose.yml`, `docs/oracle.service` (systemd). Зависимости: `requirements.txt` — для работы, `requirements-voice.txt` — локальный whisper, `requirements-dev.txt` — тесты.
